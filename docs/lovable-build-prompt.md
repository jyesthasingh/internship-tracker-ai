# Prompt to build v1 (paste into Lovable or Claude, then edit)

Build a simple web app called "[Product name]" for students tracking job and internship applications.

Features:
1. A table of applications with: company, role, link, stage (Saved, Applied, Interview, Offer, Rejected), deadline, resume version, notes, next step.
2. Add / edit / delete an application in under 30 seconds.
3. Show upcoming deadlines at the top, sorted by date, highlighting anything due in 3 days.
4. An "Ask AI" box: the user pastes a job description and picks from their saved resume versions; the AI suggests which version fits best and gives 3 reasons. It must not invent experience.

Design: clean, mobile friendly, one page. Store data per user. No payments, no email sync.
