# Internship Tracker AI

An AI-assisted tracker for students applying to many internships and jobs at once. Built solo: interview classmates, scope a small v1, ship it, and cut what people ignore.

**Live page:** https://jyesthasingh.github.io/internship-tracker-ai/
**Status:** In progress. Interviews first, then the v1 build.

## The problem
Tracking dozens of applications across notes, sheets and emails breaks down: missed deadlines, lost follow-ups, and not knowing which resume version went where. The interviews will show whether classmates hit the same problems.

## Method
1. Interview 5 classmates who are applying to many roles
2. Scope a v1 of 3 to 4 features from what they say, and write down what is cut
3. Build it and test the AI suggestion against a written set of test cases
4. Give it to the same classmates, log real usage, and write the v2 roadmap
